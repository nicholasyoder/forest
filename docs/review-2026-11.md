# Code review 2026-11: Forest work items

Work items from the November 2026 Forest + Biome code review, linked from
`docs/roadmap.md`. Each item is one PR into `develop` unless marked
"develop" (small enough to commit directly). IDs (`F4-5`, `X1-1`, …) name the
review findings, which live outside the repo. When an item ships, delete it
here and its roadmap entry. Effort is S/M/L; "manual" means the user has to
test it interactively.

## 0.11.x fixes

### polkit-agent
**Polkit agent rewrite.** F4-5, F4-6, F4-7. M. Manual: `pkexec true`,
Ctrl+C then `pkexec` again, two concurrent requests, a second wheel user.
- One session per identity is started at once (`polkitagent.cpp:36`); with
  two admin users the second prompt re-enters `exec()`, which returns -1 =
  "accepted", so the typed text goes to the other user's PAM, retrying every
  ~2 s (faillock risk).
- `cancelAuthentication` leaves the dialog up; a concurrent request gets a
  modal box and is never completed; a cancel followed by a new request tears
  down the new sessions (possible UAF).
- Fix: per-request state (cookie, result, session, dialog); one session for
  the identity selected in the combo (current user preselected), restarted on
  change; non-modal dialog driven by signals; cancel closes and completes;
  concurrent requests queued or completed with an error. PAM info/error
  inline, clear the password on completion, log `registerListener` failure.

### supervise-forest
**Restart `forest` on crash.** F2-1, F6-4, F2-5, F5-7. S–M. Manual:
`pkill forest`, second `forest` from a terminal.
- `forest` (panel, desktop, polkit agent, notifications, hotkeys) is started
  detached and never restarted (`sessionapp.cpp:31`).
- Factor the locker's backoff into `SupervisedProcess` and use it for both
  (`forest` min delay 1 s). `forest` claims `org.forest` before loading
  plugins and exits 0 if taken. Skip the startup overlay on respawn only if
  it's trivial (decided). Update CLAUDE.md's process model.
- Displays page stays "pending" forever if the service restarts mid-confirm
  (F5-7): watch `org.forest`, clear `pending` and reload.
- `load_defaults` moves all of `~/.config/Forest` aside whenever
  `Forest.conf` lacks `version` (F2-5): only on a truly empty config; copy
  missing files; never write an empty version; skip non-`.conf` files.
  Keep all existing migrations (decided).

### hotkey-triggers
**Hotkey trigger rework.** F4-1, F4-2, F4-3, F4-4, S0-3, X1-1, X1-3, X1-4.
M. Pairs with Biome 0.3.1 (`hotkey-triggers` there): bump
`Requires: biome >= 0.3.1` (spec main + greeter, debian). Manual: F-keys,
mic-mute, Caps Lock + Meta+L.
- `keysym_table.h` is a stale Qt4 table: F1–F10 unresolved, F11/F12 → Sun
  keysyms, ~120 keys missing; such hotkeys save but never fire.
- Decided: capture the keysym (`QKeyEvent::nativeVirtualKey()`), store a
  spec-grammar `trigger` key (lowercased per the contract), migrate existing
  entries once (covers shipped Meta+L etc.), delete `keysym_table.h`. Allow
  Print/Return; build modifiers from `QKeyCombination`; Esc cancels.
- Parse `BindShortcuts` results and surface unbound ids in the page (X1-3);
  refuse the same bare keys Biome refuses at capture.
- Repeat runs until `Deactivated`: cap a run (~5 s) and stop on lock (X1-4).
- Hotkeys page: modal edit dialog, resume on destroy, id assigned at save
  (F4-4); guard `parseDBusAction` (S0-3); drop `on_*` auto-connect slots.

### fileops-replace
**Transactional replace.** F7-2, F7-9. M. Scratch-dir test.
- Replace deletes the old destination before the copy succeeds
  (`filejob.cpp:212`): a failed/cancelled copy leaves neither. Copy to a
  `.part` temp in the destination, rename over on success.
- New files are created 0666&umask then chmod'ed after the data; merges
  overwrite the target folder's mode. Open with the final restricted mode;
  only chmod folders the job created.

### launcher-trust
**Desktop `.desktop` trust.** F7-3, F7-8. S. Manual.
- Any `*.desktop` on the desktop runs on double-click and shows its own
  `Name=`/`Icon=` (`desktop.cpp:343-354`) — classic phishing vector.
  Decided: launch only with `+x`; otherwise a "Trust and launch?" dialog
  that sets it; show the real filename for untrusted files.
- Main menu "Show on desktop": `XdgDirs::userDir(Desktop)`, `fileops::copy`,
  mark executable (decided). Launch with an xdg-activation token;
  `xdg-open` for folders.

### wallpaper-by-value
**Wallpaper API by value, mode by name.** F1-1, F1-2, F1-11, F5-5, F6-9,
F7-7, S0-4. M. Manual: desktop, login screen, lock screen, Login & Lock
Wallpaper page.
- `get_wallpaper_scaled` returns owning `QImage*` that nobody frees: each
  wallpaper change leaks ~230 MB on two 4K screens in the `forest` process
  (`miscutills.cpp:56-115`, `wallpaperwidget`, `GS::load`). Return `QImage`
  by value; decode only when the path changes; scale once per screen;
  `loginui::Wallpaper` decodes once, scales on resize, not in `paintEvent`.
- Decided: drop Tile; store the mode by name (item data, not combo index);
  read legacy ints, mapping 3/Tile/unknown → Fill. `forest-login-helper`
  takes a name from an allowlist (accept old ints during the transition) and
  checks `in.open`.
- `desktopconfig.h` for `desktop/wallpaper`/`imagemode`; Wallpaper page on
  `SettingsBinder`; async reload call; correct preview and file filter.

### applet-teardown
**Applet reload leaks.** F2-4, F3a-3, F3b-9, F3b-8, F3a-2. S.
- Every applet toggle/reorder (`reloadplugins`) leaks unparented timers
  (clock 1 Hz, cpu/mem 2 Hz, sensors), popups, the whole main-menu UI and
  its `.desktop` watcher, which keeps rescanning. Parent timers/helpers,
  delete popups in destructors (keep them unparented: stylesheet cascade).
  State the ownership contract in `panelpluginterface.h`.
- Windowlist preview of a closed window stays up (F3b-8): close it when the
  button goes; parent `imagepopup` and its timers.
- `panelbutton::setText` early-out on unchanged text (clock restyles every
  second); clock timer re-armed to the next second/minute boundary.

## 0.12.0

### desktop-icon-view
**Desktop icon view rework.** F7-4, F7-5, F7-6, F7-10, X1-13. M–L. Manual.
Before the desktop icons settings page.
- Every `~/Desktop` change rebuilds all icons on the `forest` UI thread and
  rewrites Forest.conf (O(N²) for an N-file paste); each label repaint
  recomputes a per-pixel blur (~3.6 ms); grid overflow leaves ghost icons;
  stored positions aren't clamped.
- Likely a `QListView` IconMode over `QFileSystemModel` (debounced,
  incremental) with a cached shadow pixmap. Put the grid on its own
  Bottom-layer surface anchored to all edges with exclusive zone 0: its
  configured size is the usable area on any compositor (fixes icons under a
  top panel).

### theme-css
**Theme CSS consolidation.** F8-1, F8-2, F8-3, F1-4, F2-6, F1-8, S0-9. M.
Manual: all four themes (small colour shifts OK, decided). Before custom
accent colour; Biome regenerates `builtin.qss` after (`theme-coupling`).
- ~40% of the shape layers and all of dark/light repeat each other; hoist
  shape-independent rules into `base`, write colours with `palette()`,
  group the 11× hover outline. Circle's scrollbar handle colour lives in the
  shape layer (F8-2). Delete dead selectors (F8-3).
- Icon sizes via `qproperty-iconSize` instead of the regex over the app
  stylesheet (ignores theme overrides); `panelbutton` sizes text from font
  metrics instead of a per-widget stylesheet; one press guard.
- `foresttheme::list()` and one default-theme constant (also used by the
  Biome drop-in); delete dead `fstyleloader.cpp`/`loadstyle()`.

### workspace-ids
**Key workspaces on ext-workspace `id`.** X1-2, F1-9. S. Pairs with Biome
0.4.0 `server-split` (sends ids); either order.
- `org.biome.Workspaces` ints are matched to ext-workspace arrival order.

## 0.14.0

### applet-api-v4
**Multi-instance applet API.** F3a-4, F3a-9, F1-10, F2-3, F2-8, F2-9, F5-8,
F2-7, F3b-10, F3b-13 (shared tracker). L. Before multiple panels (#53).
- Decided: applets are created per Panel.conf entry by a factory with an
  instance id; Panel.conf stores applet names (one migration from absolute
  paths); Panel Settings gets "Add applet" and keeps unresolvable rows.
- Host owns the applet context menu (battery and tray have none today) and
  one shared toplevel tracker; popups take their edge from the layer
  surface, not Panel.conf; one plugin loader helper with interface IIDs.
- Fixed D-Bus paths conflict with instances: volume keys already moved
  (`volume-backend`); main-menu/quicklaunch path ownership is undecided.

### app-index
**Main menu app index.** F3b-5, F3b-7, F3b-13 (index). M. Before combined
taskbar (#55).
- No desktop-file-ID precedence: user overrides can't hide apps and show
  twice. Every applications-dir change triggers an undebounced full parse
  and widget rebuild (3 parses per app); search rebuilds widgets per key.
- One parsed, debounced, ID-keyed index in `library/` (also for
  windowlist icons, with a `StartupWMClass` fallback); filter instead of
  rebuild; search `GenericName`/`Keywords`.
