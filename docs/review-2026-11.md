# Code review 2026-11: Forest work items

Work items from the November 2026 Forest + Biome code review, linked from
`docs/roadmap.md`. Each item is one PR into `develop` unless marked
"develop" (small enough to commit directly). IDs (`F4-5`, `X1-1`, …) name the
review findings, which live outside the repo. When an item ships, delete it
here and its roadmap entry. Effort is S/M/L; "manual" means the user has to
test it interactively.

## 0.12.0

### theme-css
**Theme CSS consolidation.** F8-1, F8-2, F8-3, F1-4, F2-6, F1-8, S0-9. M.
Manual: all four themes (small colour shifts OK, decided). Before custom
accent colour; Biome regenerates `builtin.qss` after (`theme-coupling`).
- ~40% of the shape layers and all of dark/light repeat each other; hoist
  shape-independent rules into `base`, write colours with `palette()`,
  group the 11× hover outline. Circle's scrollbar handle colour lives in the
  shape layer (F8-2). Delete dead selectors (F8-3).
- Icon sizes via `qproperty-iconSize` instead of the regex over the app
  stylesheet (ignores theme overrides); `panelbutton` sizes text from font
  metrics instead of a per-widget stylesheet; one press guard.
- `foresttheme::list()` and one default-theme constant (also used by the
  Biome drop-in); delete dead `fstyleloader.cpp`/`loadstyle()`.

## 0.13.0

### volume-backend
**libpulse volume backend (decided).** F3b-2, F3b-4, F3b-10 (volume),
F4-14. M.
- The ALSA engine drives raw mixer elements: no HDMI/Bluetooth sinks,
  keys don't follow the default sink, raw-unit steps, fights WirePlumber.
- Port lxqt-panel's `pulseaudioengine` behind the
  existing `AudioEngine`, follow the default sink, percent steps, drop
  Forest's autosave. Volume up/down/mute move to a services-app object
  (`/org/forest/volume`, decided) next to brightness; migrate the shipped
  hotkeys; the applet becomes a view.

### battery-backend
**UPower battery backend (decided).** F3a-5. S–M.
- `DisplayDevice` (combined level, `IconName`,
  `WarningLevel`) via async `PropertiesChanged`; `Requires: upower`.
  Settle how it meets #38's configurable thresholds first.

### graph-monitor
**Shared monitor base.** F3a-1, F3a-10, F5-10. M. Before system monitor
popups (#28).
- cpu and memory monitors are the same applet with a different `sample()`.
  `GraphMonitor` base + shared settings rows.
- Colours stored three ways, one parsed by a crash-prone `string_to_color`:
  `QColor` `#AARRGGBB` with a tolerant reader; `SettingsBinder::for_applet()`
  replaces the reload lambda repeated in 6 pages.

### forest-dbus
**Deliberate `org.forest` API.** F2-2, F1-5, F2-11. S–M.
- `ExportAllSlots` on `QWidget`s exports `close`, `addplugin(path)` (dlopens
  anything) etc. Switch to scriptable slots, real interface names, one
  `forestbus.h` of constants; `call_dbus` async with no introspection.
  Update CLAUDE.md's DBus section.

### portal-config
**Forest-owned portal config.** X1-5. S. Pairs with Biome 0.5.0
`portal-config`. Manual: hotkeys bind, browser screen-share picker.
- Ship `forest-portals.conf` (`default=gtk`, `GlobalShortcuts=biome`,
  `ScreenCast`/`Screenshot=wlr`), `Requires: xdg-desktop-portal-gtk`,
  `Recommends: xdg-desktop-portal-wlr` (decided). Today screen sharing has
  no backend and hotkeys depend on `biome` in `DesktopNames`.

## 0.14.0

### applet-api-v4
**Multi-instance applet API.** F3a-4, F3a-9, F1-10, F2-3, F2-8, F2-9, F5-8,
F2-7, F3b-10, F3b-13 (shared tracker). L. Before multiple panels (#53).
- Decided: applets are created per Panel.conf entry by a factory with an
  instance id; Panel.conf stores applet names (one migration from absolute
  paths); Panel Settings gets "Add applet" and keeps unresolvable rows.
- Host owns the applet context menu (battery and tray have none today) and
  one shared toplevel tracker; popups take their edge from the layer
  surface, not Panel.conf; one plugin loader helper with interface IIDs.
- Fixed D-Bus paths conflict with instances: volume keys already moved
  (`volume-backend`); main-menu/quicklaunch path ownership is undecided.

### app-index
**Main menu app index.** F3b-5, F3b-7, F3b-13 (index). M. Before combined
taskbar (#55).
- No desktop-file-ID precedence: user overrides can't hide apps and show
  twice. Every applications-dir change triggers an undebounced full parse
  and widget rebuild (3 parses per app); search rebuilds widgets per key.
- One parsed, debounced, ID-keyed index in `library/` (also for
  windowlist icons, with a `StartupWMClass` fallback); filter instead of
  rebuild; search `GenericName`/`Keywords`.

## Later

### library-cleanup
**Library and CMake cleanup.** F1-3, F1-7, F1-13, F1-14, F8-7, F8-8, F8-9,
S0-7, S0-12. M. Best before `applet-api-v4`.
- `OutputManager` can't be torn down safely; use Qt's `destruct` hook and
  one shared release helper; one singleton idiom.
- Break up `miscutills` (wallpaper unit, `ScreenTracker`; Qt replaces
  `RunOnce`, pad and colour helpers). PUBLIC include dirs; applet/settings/
  app-plugin CMake helpers; drop dead defines and one-line wrappers;
  `find_package(qt6xdg)`; unused links. Mechanical clang-tidy pass.

### record-lists
**Record lists as QSettings arrays.** F5-4, F1-7. M.
- Hotkeys, autostart, quicklaunch and panel lists hand-number `item-NNNN`
  groups and renumber on remove (the cause of an autostart crash and the
  hotkey id race). `beginWriteArray` with tolerant readers.

### services-process
**Session services outside the applet process (needs decision).** F2-1
(item 3), F4-14.
- An applet crash takes down the polkit agent, notifications and the SNI
  watcher with the panel. Supervision (0.11.1) restores them; moving them
  to their own process would avoid the outage.
