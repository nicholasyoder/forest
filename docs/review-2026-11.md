# Code review 2026-11: Forest work items

Work items from the November 2026 Forest + Biome code review, linked from
`docs/roadmap.md`. Each item is one PR into `develop` unless marked
"develop" (small enough to commit directly). IDs (`F4-5`, `X1-1`, …) name the
review findings, which live outside the repo. When an item ships, delete it
here and its roadmap entry. Effort is S/M/L; "manual" means the user has to
test it interactively.

## 0.11.x fixes

### applet-teardown
**Applet reload leaks.** F2-4, F3a-3, F3b-9, F3b-8, F3a-2. S.
- Every applet toggle/reorder (`reloadplugins`) leaks unparented timers
  (clock 1 Hz, cpu/mem 2 Hz, sensors), popups, the whole main-menu UI and
  its `.desktop` watcher, which keeps rescanning. Parent timers/helpers,
  delete popups in destructors (keep them unparented: stylesheet cascade).
  State the ownership contract in `panelpluginterface.h`.
- Windowlist preview of a closed window stays up (F3b-8): close it when the
  button goes; parent `imagepopup` and its timers.
- `panelbutton::setText` early-out on unchanged text (clock restyles every
  second); clock timer re-armed to the next second/minute boundary.


### notification-popups
**Notification popup fixes.** F4-8, F4-9, F4-10, F4-11. S–M. Manual visual.
- `expire_timeout = 0` must never expire; a Default of 0 closes every popup
  at once; enforce min ≤ max.
- Labels use `AutoText`, so HTML half-renders though `body-markup` isn't
  advertised: `Qt::PlainText`.
- `replaces_id` destroys and remaps the surface: update in place.
  `CloseNotification` on an unknown id returns an error.
- Each popup ticks a 10 ms timer rendering a hidden frame into a fresh pixmap:
  `QVariantAnimation`, paint the bar directly; cap visible popups; margins
  from the polished layout, not a stylesheet regex.

### mainmenu-fixes
**Main menu interaction fixes.** F3b-6, F3b-7 (timer). S.
- Right-click/drag act on the keyboard-focused item, not the clicked one;
  right-clicking a category inserts an empty app (`appHash[...]`), after
  which clicking it launches `""`. Pass the clicked uuid; never `operator[]`
  on reads; app items only; init `currentState`; `WA_DeleteOnClose` on
  Properties.
- After the first search a repeating 2 Hz timer runs forever: single-shot.

### applet-fixes
**Monitor, tray, quicklaunch and volume fixes.** F3a-5 (stopgap), F3a-6,
F3a-7, F3a-8, F3b-11, F3b-3, F3b-12. S–M.
- Battery: no warning while charging; hide the applet with no battery
  (decided); keep the returned notification id.
- CPU counts iowait (and guest time twice); meminfo parsed by line position;
  interval 0 busy-loops.
- Sensors re-read every hwmon sensor and rebuild the popup HTML every tick;
  "0C°" with no sensors; theme colours for text mode.
- Quicklaunch: multi-file drop keeps one; paths not URL-decoded
  (`toLocalFile()`); key-by-count overwrite.
- Tray: honour `ItemIsMenu`; accumulate hi-res scroll; cache icon-path scans.
- Volume stopgap (skip if `volume-backend` lands first): mute toggles the
  playback switch instead of zeroing volume; wheel ignores x and accumulates.

### settings-fixes
**Settings and displays fixes.** F5-2, F5-3, F5-6, F5-9, F1-6, F5-11,
F5-12, F1-15, F2-3 (stopgap), F4-13, X1-11, S0-5. S–M.
- A page rebuild force-switches the visible page (`settingsmanager.cpp:520`);
  `opened` fires before a page's widgets exist.
- Cursor page rewrites `index.theme` on open and per keystroke, scans XDG
  data dirs as icon dirs.
- About runs six `bash` pipelines per open: `QSysInfo` + `/proc`, build
  version. Build `DisplaysPage`'s manager on first open.
- Rename the wallpaper page "Login & Lock Wallpaper" (decided); fix the
  "Services → Hotkeys" note; drop the dead `system` category.
- `settings_widget`: `QPointer` + `deleteLater` in `clear()`.
- Panel page: keep `Panel.conf` rows it can't read instead of erasing them.
- Primary-screen fallback and `display/primary_screen` key shared via
  `outputs::`; displays service re-applies the profile if a reconnected
  monitor didn't come back as saved (not every compositor restores).
- `invalidateRowsFilter` → `begin/endFilterChange`; `globalPosition()`.

### login-fixes
**Greeter, logout and session fixes.** F6-7, F6-10, F6-11, X1-12. S.
Manual: greeter.
- greetd client infers responses from current state: keep a FIFO of
  requests; show an error when no session entry exists.
- Users from `getpwent()` (NSS/SSSD), sessions via `XdgDesktopFile`
  (Hidden/TryExec/localized); shared GECOS and signalfd helpers.
- Logout: null `focusbt` on an unknown `lastaction`; interactive logind calls
  async (25 s timeout reports failure while polkit is still prompting).
- Greeter focus comment is wrong about Biome; don't rely on map order.

### screenshot-fixes
**Screenshot fixes and ext-data-control.** F7-11, F7-12, S0-2, X1-6. S.
- PNG encoded twice; clipboard reported copied before the helper owns it.
- `compose` = `crop(union)`; early `done({})` with no screens.
- Bind `ext_data_control_manager_v1` first, `zwlr_…` as fallback (works on

### dead-code
**Dead-code sweep.** F2-10, F3a-11, F3b-14, F4-12, S0-11. S. Pieces can go

## 0.12.0

### desktop-icon-view
**Desktop icon view rework.** F7-4, F7-5, F7-6, F7-10, X1-13. M–L. Manual.
Before the desktop icons settings page.
- Every `~/Desktop` change rebuilds all icons on the `forest` UI thread and
  rewrites Forest.conf (O(N²) for an N-file paste); each label repaint
  recomputes a per-pixel blur (~3.6 ms); grid overflow leaves ghost icons;
  stored positions aren't clamped.
- Likely a `QListView` IconMode over `QFileSystemModel` (debounced,
  incremental) with a cached shadow pixmap. Put the grid on its own
  Bottom-layer surface anchored to all edges with exclusive zone 0: its
  configured size is the usable area on any compositor (fixes icons under a
  top panel).

### theme-css
**Theme CSS consolidation.** F8-1, F8-2, F8-3, F1-4, F2-6, F1-8, S0-9. M.
Manual: all four themes (small colour shifts OK, decided). Before custom
accent colour; Biome regenerates `builtin.qss` after (`theme-coupling`).
- ~40% of the shape layers and all of dark/light repeat each other; hoist
  shape-independent rules into `base`, write colours with `palette()`,
  group the 11× hover outline. Circle's scrollbar handle colour lives in the
  shape layer (F8-2). Delete dead selectors (F8-3).
- Icon sizes via `qproperty-iconSize` instead of the regex over the app
  stylesheet (ignores theme overrides); `panelbutton` sizes text from font
  metrics instead of a per-widget stylesheet; one press guard.
- `foresttheme::list()` and one default-theme constant (also used by the
  Biome drop-in); delete dead `fstyleloader.cpp`/`loadstyle()`.

### workspace-ids
**Key workspaces on ext-workspace `id`.** X1-2, F1-9. S. Pairs with Biome
0.4.0 `server-split` (sends ids); either order.
- `org.biome.Workspaces` ints are matched to ext-workspace arrival order.
  Store the handle `id`, fall back to arrival order. Let deskswitch reuse
  the tracker's workspace client; a no-workspaces tracker mode for the
  screenshot CLI.

## 0.13.0

### volume-backend
**libpulse volume backend (decided).** F3b-2, F3b-4, F3b-10 (volume),
F4-14. M.
- The ALSA engine drives raw mixer elements: no HDMI/Bluetooth sinks,
  keys don't follow the default sink, raw-unit steps, fights WirePlumber.
- Port lxqt-panel's `pulseaudioengine` behind the
  existing `AudioEngine`, follow the default sink, percent steps, drop
  Forest's autosave. Volume up/down/mute move to a services-app object
  (`/org/forest/volume`, decided) next to brightness; migrate the shipped
  hotkeys; the applet becomes a view.

### battery-backend
**UPower battery backend (decided).** F3a-5. S–M.
- `DisplayDevice` (combined level, `IconName`,
  `WarningLevel`) via async `PropertiesChanged`; `Requires: upower`.
  Settle how it meets #38's configurable thresholds first.

### graph-monitor
**Shared monitor base.** F3a-1, F3a-10, F5-10. M. Before system monitor
popups (#28).
- cpu and memory monitors are the same applet with a different `sample()`.
  `GraphMonitor` base + shared settings rows.
- Colours stored three ways, one parsed by a crash-prone `string_to_color`:
  `QColor` `#AARRGGBB` with a tolerant reader; `SettingsBinder::for_applet()`
  replaces the reload lambda repeated in 6 pages.

### forest-dbus
**Deliberate `org.forest` API.** F2-2, F1-5, F2-11. S–M.
- `ExportAllSlots` on `QWidget`s exports `close`, `addplugin(path)` (dlopens
  anything) etc. Switch to scriptable slots, real interface names, one
  `forestbus.h` of constants; `call_dbus` async with no introspection.
  Update CLAUDE.md's DBus section.

### portal-config
**Forest-owned portal config.** X1-5. S. Pairs with Biome 0.5.0
`portal-config`. Manual: hotkeys bind, browser screen-share picker.
- Ship `forest-portals.conf` (`default=gtk`, `GlobalShortcuts=biome`,

## 0.14.0

### applet-api-v4
**Multi-instance applet API.** F3a-4, F3a-9, F1-10, F2-3, F2-8, F2-9, F5-8,
F2-7, F3b-10, F3b-13 (shared tracker). L. Before multiple panels (#53).
- Decided: applets are created per Panel.conf entry by a factory with an
  instance id; Panel.conf stores applet names (one migration from absolute
  paths); Panel Settings gets "Add applet" and keeps unresolvable rows.
- Host owns the applet context menu (battery and tray have none today) and
  one shared toplevel tracker; popups take their edge from the layer
  surface, not Panel.conf; one plugin loader helper with interface IIDs.
- Fixed D-Bus paths conflict with instances: volume keys already moved
  (`volume-backend`); main-menu/quicklaunch path ownership is undecided.

### app-index
**Main menu app index.** F3b-5, F3b-7, F3b-13 (index). M. Before combined
taskbar (#55).
- No desktop-file-ID precedence: user overrides can't hide apps and show
  twice. Every applications-dir change triggers an undebounced full parse
  and widget rebuild (3 parses per app); search rebuilds widgets per key.
- One parsed, debounced, ID-keyed index in `library/` (also for
  windowlist icons, with a `StartupWMClass` fallback); filter instead of
  rebuild; search `GenericName`/`Keywords`.
